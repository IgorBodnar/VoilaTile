# Release Notes

Here you’ll find the main highlights for each VoilaTile release.  
For full technical changelogs, see the [GitHub Releases](https://github.com/IgorBodnar/VoilaTile/releases).

---

## v1.0.0 — Initial Public Release

**Date:** November 2025  
**Highlights:**
- ✨ First stable version of VoilaTile
- 🧱 Includes **Snap Mode**, **Jump Mode**, and **Look Mode**
- ⚙️ New **Settings** app for layouts, hints & appearance
- 🚀 Installer with custom options:
  - Launch Snapper on Windows startup
  - Open Settings after installation
- 🧩 Automatic update support via installer re-run

---
