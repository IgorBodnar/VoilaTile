<p>
VoilaTile is lightweight Windows utility that lets you create, save and instantly snap into fully custom window layouts.
It is built for speed, precision and <strong>keyboard-first workflow</strong> that keeps your hands where the action is.
</p>

<p>
VoilaTile takes the idea of custom window layouts — popularized by tools like Microsoft's FancyZones — and fine-tunes it for the users who <strong>live on the keyboard</strong>.<br><br>
It is not about automatic tiling like i3 or Hyprland, nor is it about rigid layouts.
Instead, VoilaTile lets you create and save layouts that match your exact workflow, then effortlessly snap windows into place.
</p>

<p>
VoilaTile is <strong>multi-monitor</strong> and <strong>DPI</strong> aware and stores layout per <strong>physical monitor device</strong>, meaning your workspace will always be exactly how you designed it.
</p>

## Features

- **Snap Mode** - Hint-based, ultra-fast window snapping
- **Jump Mode** - Effortlessly jump focus across visible windows
- **Look Mode** - Alt+Tab like preview with window thumbnails, hint-based selection and more
- **Settings** - Customise layouts, hints & shortcuts, appearance
